# Bitsocial Docs

The Docusaurus site served at [docs.bitsocial.net](https://docs.bitsocial.net/): protocol notes, roadmap, app and developer-tool guides, and contributor playbooks, in 36 languages.

This repository was split out of the `docs/` directory of [bitsocial-web](https://github.com/bitsocialnet/bitsocial-web) with its history. Pull request and issue numbers in older commit messages refer to bitsocial-web.

## Requirements

- Node.js 22 (see `.nvmrc`)
- Yarn 4 through Corepack (`corepack enable`)
- Python 3 with `deep_translator`, only for the translation helpers in `scripts/`

## Commands

| Command                                            | What it does                                                                                                                          |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `corepack yarn install`                            | Install dependencies                                                                                                                  |
| `yarn start:docs`                                  | Build every locale and serve the multi-locale preview with search at `https://docs.bitsocial.localhost` (`PORTLESS=0` skips Portless) |
| `yarn start:docs:live`                             | The same URL with the single-locale Docusaurus dev server and hot reload                                                              |
| `yarn start`                                       | Plain `docusaurus start` on `http://localhost:3000`                                                                                   |
| `yarn build`                                       | Production build into `build/`: every locale, then the Pagefind search index                                                          |
| `yarn build:verify`                                | English-only build                                                                                                                    |
| `yarn typecheck`, `yarn lint`, `yarn format:check` | Type, lint and format checks                                                                                                          |
| `node --test scripts/__tests__/*.node-test.mjs`    | Tests for the docs client state, dev-server launcher and AI workflow tooling                                                          |

## Layout

- Pages: Markdown and MDX at the root and in `agent-playbooks/`, `anti-spam/`, `apps/`, `comparisons/`, `developer-tools/` and `infrastructure/`. The sidebar is `sidebars.ts`.
- Translations: `i18n/<locale>/`.
- Theme overrides, components and client modules: `src/`. Static files, including the served `llms.txt` and `llms-full.txt`: `static/`.
- Repository tooling, not rendered: `scripts/`, `.agents/`, `.claude/`, `.codex/`, `.github/`.

The docs content root is the repository root, so every Markdown file becomes a page unless the `exclude` list in `docusaurus.config.ts` covers it.

`static/llms.txt` and `static/llms-full.txt` are generated by the cross-site llms generator, which reads the about, chain and docs sources together and lives outside this repository. Do not edit them by hand.

## Deployment

The Vercel project `bitsocial-docs` runs `yarn build` and serves `build/`.
