# Spam Blocker

Spam Blocker는 커뮤니티가 게시물, 답글, 투표를 받아들이기 전에 스팸 위험 점수를 매깁니다. 커뮤니티가 챌린지 패키지를 설치하면, 이 패키지가 각 발행물을 스팸 차단 서비스로 보냅니다. Bitsocial은 `spamblocker.bitsocial.net`에서 이러한 서비스를 하나 운영합니다.

- **`@bitsocial/spam-blocker-challenge`**: 커뮤니티가 설치하는 오픈 소스 챌린지 패키지입니다. 통합 계약, 공유 스키마, API가 공개되어 있습니다.
- **호스팅 서비스**: 발행물의 점수를 매기고 CAPTCHA 및 로그인 페이지를 제공합니다. [소스 정책](https://github.com/bitsocialnet/spam-blocker/blob/master/docs/architecture/hosted-service-source-policy.md)에서 설명하듯이 세부 가중치와 휴리스틱은 비공개입니다.

**소스 코드:** [github.com/bitsocialnet/spam-blocker](https://github.com/bitsocialnet/spam-blocker)

## 발행물 검사 방식

1. 커뮤니티의 챌린지가 서명된 발행물을 서비스로 보내면, 서비스는 0에서 1 사이의 위험 점수를 반환합니다.
2. 점수가 커뮤니티의 자동 승인 임계값보다 낮으면 발행물이 통과합니다. 자동 거부 임계값 이상이면 실패하며, 작성자에게 그 이유가 표시됩니다.
3. 그 사이라면, 지난 30일 이내의 작성자 로그인으로 충분할 경우 이를 재사용합니다. 그렇지 않으면 작성자에게 확인 페이지가 표시됩니다. CAPTCHA만으로 통과할 수 있으면 CAPTCHA가, 그렇지 않으면 로그인이 요구됩니다.
4. 그런 다음 커뮤니티는 서비스에 결과를 확인하고, 국가, IP 위험도, 연결 유형에 대한 자체 규칙을 적용합니다.

첨부 파일을 업로드하기 전에 클라이언트는 같은 검사를 사전 검사로 실행할 수 있으므로, 거부될 작성자는 아예 업로드하지 않게 됩니다.

## 위험 점수

| 신호           | 설명                                                                                                    |
| -------------- | ------------------------------------------------------------------------------------------------------- |
| 계정 연령      | 새로운 계정은 더 높은 위험 점수를 받습니다.                                                             |
| 카르마         | 축적된 커뮤니티 카르마는 위험을 줄입니다.                                                               |
| 저자 평판      | 여러 커뮤니티에서 어떤 작성자가 승인, 삭제 또는 차단되는지 추적하는 백그라운드 인덱서의 데이터입니다.   |
| 콘텐츠 및 링크 | 반복되는 콘텐츠를 포함한 텍스트 및 링크 분석입니다.                                                     |
| 속도           | 동일한 작성자의 빠른 연속 게시물은 위험을 증가시킵니다.                                                 |
| IP 인텔리전스  | 연결 유형(Tor, VPN, 프록시, 데이터센터)과 IP 위험도입니다. 원시 IP 주소는 커뮤니티와 공유되지 않습니다. |
| 연관 계정      | 하나의 네트워크에서 많은 계정이 게시하면 위험이 점진적으로 높아집니다.                                  |
| 소셜 인증      | 작성자 계정에 대한 이전 로그인 기록은 위험을 낮춥니다.                                                  |

## 확인

완료된 각 단계는 위험 점수에 배수를 곱하며, 결과가 0.4 미만이면 발행물이 통과합니다.

| 단계                                   | 배수         |
| -------------------------------------- | ------------ |
| CAPTCHA (Cloudflare Turnstile)         | × 0.7        |
| Google, Apple 또는 Telegram으로 로그인 | × 0.6        |
| 두 번째의 다른 제공업체로 로그인       | 추가로 × 0.5 |

CAPTCHA로 충분하지 않으면 이어서 로그인을 진행합니다. 로그인으로 충분하지 않으면, CAPTCHA로 검사를 마칠 수 있을 때는 CAPTCHA를, 그렇지 않으면 두 번째 제공업체 로그인을 진행합니다.

### 기억된 로그인

서비스는 작성자가 마지막으로 로그인한 계정을 기억합니다. 작성자가 그 계정으로 적어도 30일에 한 번 이상 계속 게시하는 한, 이후 확인이 필요한 게시물은 작성자가 다시 로그인한 것처럼 이 계정을 재사용합니다. 그것으로 충분하면 게시물은 CAPTCHA 없이 통과합니다. 커뮤니티에서 이 계정에 연결된 차단이 발생하면 이 기능은 종료되며, 해당 계정의 제공업체가 서비스에서 제거되어도 마찬가지입니다.

## 연결 정책

커뮤니티는 Tor, VPN(iCloud Private Relay 포함), 프록시, 데이터센터 연결에서 오는 발행물을 제한할 수 있습니다. 호스팅 서비스에서는 다음과 같이 처리합니다.

- **VPN, 프록시, 데이터센터 연결**은 로그인한 후 게시할 수 있습니다. 페이지에서는 로그인이 필요한 이유와 VPN을 꺼서 로그인 없이 게시하는 방법을 설명합니다. 이후 커뮤니티의 차단은 로그인에 사용한 계정에도 적용됩니다.
- **신뢰가 쌓인 계정**, 즉 제한되지 않은 연결에서 서로 다른 3일에 걸쳐 검사를 통과한 계정은 예외입니다.
- **Tor**는 계속 제한됩니다. 단, 커뮤니티가 설정한 예외(모더레이터 역할, 커뮤니티의 화이트리스트 또는 확인된 `.bso` 이름)에 해당하는 작성자는 제외됩니다.

Forge Images에 업로드되는 첨부 파일에도 같은 규칙이 적용됩니다. VPN, 프록시 또는 데이터센터 연결을 통해 업로드하려면 로그인으로 통과한 사전 검사 또는 신뢰가 쌓인 계정이 필요합니다. Tor를 통해 업로드하려면 확인된 예외가 필요합니다.

## 개인 정보 보호

- **운영자**는 악용 탐지를 위해 원시 IP 주소와 발행물 콘텐츠를 저장하고, 분류를 위해 IP 주소를 제3자 제공업체(기본값은 proxycheck.io)로 보냅니다.
- **커뮤니티**는 국가 코드, IP 위험도, 연결 유형 추정치, 통과 또는 실패 결과만 받습니다. 원시 IP나 로그인 계정은 절대 받지 않습니다.
- **로그인**은 프로필 데이터를 요청하지 않습니다. 서비스는 Google, Apple 또는 Telegram에서 계정 ID만 받으며, 이름, 이메일, 사진은 절대 받지 않습니다. 이 ID는 자동 삭제 없이 게시물과 함께 보관되므로 차단은 해당 계정에도 적용됩니다.
- **VPN을 사용하는 작성자**는 로그인할 때도 실제 IP 주소가 숨겨진 상태로 유지됩니다. 서비스는 VPN의 주소만 봅니다.

## 속도 제한

서비스는 점수를 매기기 전에, 게시물, 답글, 투표에 대한 시간당 또는 일일 한도를 초과한 작성자를 거부합니다. 한도는 계정 연령과 좋은 평판에 따라 늘어나고, 차단이나 삭제 후에는 줄어듭니다.

## API

주요 경로는 다음과 같으며, `spamblocker.bitsocial.net/api/v1`을 기준으로 합니다.

| 경로                     | 호출자                  | 용도                                  |
| ------------------------ | ----------------------- | ------------------------------------- |
| `POST /evaluate`         | 챌린지 iframe, 커뮤니티 | 발행물의 점수를 매기고 해당 세션 생성 |
| `POST /challenge/verify` | 커뮤니티                | 세션 결과와 IP 인텔리전스 조회        |
| `POST /precheck`         | 사전 검사 iframe        | 업로드 전 초안의 점수 산정            |
| `GET /iframe/:sessionId` | 작성자의 브라우저       | 확인 페이지                           |
| `POST /upload/authorize` | 작성자의 클라이언트     | Forge Images용 첨부 파일 승인         |

요청 서명과 응답 스키마를 포함한 전체 계약은 [spam-blocker README](https://github.com/bitsocialnet/spam-blocker#api-contract)에 있습니다.
