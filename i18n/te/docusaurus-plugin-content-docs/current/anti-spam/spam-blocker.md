# Spam Blocker

ఒక కమ్యూనిటీ పోస్ట్‌లు, ప్రత్యుత్తరాలు మరియు ఓట్లను ఆమోదించే ముందు Spam Blocker వాటికి స్పామ్ రిస్క్ స్కోర్ ఇస్తుంది. కమ్యూనిటీ ఛాలెంజ్ ప్యాకేజీని ఇన్‌స్టాల్ చేస్తుంది, అది ప్రతి ప్రచురణను ఒక Spam Blocker సేవకు పంపుతుంది. Bitsocial అలాంటి ఒక సేవను `spamblocker.bitsocial.net` వద్ద నడుపుతుంది.

- **`@bitsocial/spam-blocker-challenge`** అనేది కమ్యూనిటీలు ఇన్‌స్టాల్ చేసే ఓపెన్-సోర్స్ ఛాలెంజ్ ప్యాకేజీ. దీని ఇంటిగ్రేషన్ కాంట్రాక్ట్, భాగస్వామ్య స్కీమాలు మరియు API పబ్లిక్‌గా ఉన్నాయి.
- **హోస్ట్ చేయబడిన సేవ** ప్రచురణలకు స్కోర్ ఇస్తుంది మరియు CAPTCHA, సైన్-ఇన్ పేజీలను అందిస్తుంది. [సోర్స్ విధానం](https://github.com/bitsocialnet/spam-blocker/blob/master/docs/architecture/hosted-service-source-policy.md)లో వివరించినట్లుగా, దీని వివరమైన వెయిట్‌లు మరియు హ్యూరిస్టిక్‌లు ప్రైవేట్‌గా ఉంటాయి.

**సోర్స్ కోడ్:** [github.com/bitsocialnet/spam-blocker](https://github.com/bitsocialnet/spam-blocker)

## ఒక ప్రచురణ ఎలా తనిఖీ చేయబడుతుంది

1. కమ్యూనిటీ ఛాలెంజ్ సంతకం చేసిన ప్రచురణను సేవకు పంపుతుంది, సేవ 0 మరియు 1 మధ్య ఒక రిస్క్ స్కోర్‌ను తిరిగి ఇస్తుంది.
2. స్కోర్ కమ్యూనిటీ స్వయంచాలక ఆమోద పరిమితి కంటే తక్కువగా ఉంటే, ప్రచురణ ఆమోదం పొందుతుంది. స్వయంచాలక తిరస్కరణ పరిమితికి సమానంగా లేదా అంతకంటే ఎక్కువగా ఉంటే, అది తిరస్కరించబడుతుంది మరియు ఎందుకో రచయితకు కనిపిస్తుంది.
3. ఈ రెండింటి మధ్య ఉంటే, గత 30 రోజులలో రచయిత చేసిన సైన్-ఇన్ సరిపోతే దాన్నే మళ్లీ ఉపయోగిస్తారు. లేకపోతే రచయితకు ఒక ధృవీకరణ పేజీ చూపబడుతుంది: CAPTCHA ఒక్కటే సరిపోయే సందర్భంలో CAPTCHA, లేకపోతే సైన్-ఇన్.
4. ఆ తర్వాత కమ్యూనిటీ ఫలితాన్ని సేవతో సరిచూసుకుని, దేశం, IP రిస్క్ మరియు కనెక్షన్ రకం విషయంలో తన సొంత నియమాలను వర్తింపజేస్తుంది.

జత చేసిన ఫైల్‌ను అప్‌లోడ్ చేసే ముందు, క్లయింట్ అదే తనిఖీని ముందస్తు తనిఖీగా నడపవచ్చు, తద్వారా తిరస్కరించబడే రచయితలు అసలు అప్‌లోడ్ చేయరు.

| సంకేతం                 | వివరణ                                                                                                                                     |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| ఖాతా వయస్సు            | కొత్త ఖాతాలకు ఎక్కువ రిస్క్ స్కోర్‌లు లభిస్తాయి.                                                                                          |
| కర్మ                   | కమ్యూనిటీలో సంపాదించిన కర్మ రిస్క్‌ను తగ్గిస్తుంది.                                                                                       |
| రచయిత ప్రతిష్ఠ         | కమ్యూనిటీల అంతటా ఏ రచయితలు ఆమోదించబడుతున్నారు, తొలగించబడుతున్నారు లేదా నిషేధించబడుతున్నారో ట్రాక్ చేసే నేపథ్య ఇండెక్సర్ నుండి వచ్చే డేటా. |
| కంటెంట్ మరియు లింక్‌లు | పునరావృత కంటెంట్‌తో సహా టెక్స్ట్ మరియు లింక్ విశ్లేషణ.                                                                                    |
| వేగం                   | ఒకే రచయిత నుండి వరుసగా వేగంగా వచ్చే పోస్ట్‌లు రిస్క్‌ను పెంచుతాయి.                                                                        |
| IP సమాచారం             | కనెక్షన్ రకం (Tor, VPN, ప్రాక్సీ, డేటాసెంటర్) మరియు IP రిస్క్. ముడి IP చిరునామాలు కమ్యూనిటీలతో ఎప్పుడూ పంచుకోబడవు.                        |
| లింక్ చేయబడిన ఖాతాలు   | ఒకే నెట్‌వర్క్ నుండి అనేక ఖాతాలు పోస్ట్ చేస్తే రిస్క్ క్రమంగా పెరుగుతుంది.                                                                |
| సామాజిక ధృవీకరణ        | రచయిత ఖాతాతో గతంలో చేసిన సైన్-ఇన్‌లు రిస్క్‌ను తగ్గిస్తాయి.                                                                               |

## ధృవీకరణ

పూర్తి చేసిన ప్రతి దశ రిస్క్ స్కోర్‌ను ఒక గుణకంతో గుణిస్తుంది, ఫలితం 0.4 కంటే తక్కువైనప్పుడు ప్రచురణ ఆమోదం పొందుతుంది.

| దశ                                          | గుణకం     |
| ------------------------------------------- | --------- |
| CAPTCHA (Cloudflare Turnstile)              | × 0.7     |
| Google, Apple లేదా Telegram ద్వారా సైన్-ఇన్ | × 0.6     |
| రెండవ, వేరే ప్రొవైడర్ ద్వారా సైన్-ఇన్       | మరో × 0.5 |

CAPTCHA సరిపోకపోతే, దాని తర్వాత సైన్-ఇన్ వస్తుంది. సైన్-ఇన్ సరిపోకపోతే, CAPTCHAతో తనిఖీ పూర్తయ్యే పక్షంలో CAPTCHA వస్తుంది, లేకపోతే రెండవ ప్రొవైడర్ ద్వారా సైన్-ఇన్ వస్తుంది.

### గుర్తుంచుకున్న సైన్-ఇన్‌లు

రచయిత చివరిసారి ఏ ఖాతాతో సైన్ ఇన్ చేశారో సేవ గుర్తుంచుకుంటుంది. రచయిత కనీసం ప్రతి 30 రోజులకు ఒకసారి ఆ ఖాతాతో పోస్ట్ చేస్తూ ఉన్నంత కాలం, ధృవీకరణ అవసరమైన తదుపరి పోస్ట్ రచయిత మళ్లీ సైన్ ఇన్ చేసినట్లుగానే ఆ ఖాతాను తిరిగి ఉపయోగిస్తుంది. అది సరిపోయినప్పుడు, పోస్ట్ CAPTCHA లేకుండానే ఆమోదం పొందుతుంది. ఆ ఖాతాకు లింక్ చేయబడిన కమ్యూనిటీ నిషేధం దీన్ని ముగిస్తుంది, సేవ నుండి ఆ ఖాతా ప్రొవైడర్‌ను తొలగించడం కూడా దీన్ని ముగిస్తుంది.

## కనెక్షన్ విధానాలు

కమ్యూనిటీలు Tor, VPN (iCloud Private Relay తో సహా), ప్రాక్సీ మరియు డేటాసెంటర్ కనెక్షన్‌ల నుండి వచ్చే ప్రచురణలను పరిమితం చేయవచ్చు. హోస్ట్ చేయబడిన సేవలో:

- **VPN, ప్రాక్సీ మరియు డేటాసెంటర్ కనెక్షన్‌లు** సైన్-ఇన్ తర్వాత పోస్ట్ చేయవచ్చు. సైన్-ఇన్ ఎందుకు అవసరమో, VPN ను ఆఫ్ చేసి సైన్-ఇన్ లేకుండా ఎలా పోస్ట్ చేయాలో ఆ పేజీ వివరిస్తుంది. ఆ తర్వాత కమ్యూనిటీలో విధించే నిషేధం సైన్ ఇన్ చేయడానికి ఉపయోగించిన ఖాతాకు కూడా వర్తిస్తుంది.
- **స్థిరపడిన ఖాతాలు**, అంటే పరిమితి లేని కనెక్షన్‌ల నుండి 3 వేర్వేరు రోజులలో తనిఖీని దాటిన ఖాతాలకు మినహాయింపు ఉంటుంది.
- **Tor** పరిమితంగానే ఉంటుంది, కమ్యూనిటీ కాన్ఫిగర్ చేసిన మినహాయింపు ఉన్న రచయితలకు తప్ప: మోడరేటర్ పాత్ర, కమ్యూనిటీ వైట్‌లిస్ట్, లేదా ధృవీకరించబడిన `.bso` పేరు.

Forge Images కు అప్‌లోడ్ చేసే జత చేసిన ఫైల్‌లు కూడా ఇవే నియమాలను పాటిస్తాయి. VPN, ప్రాక్సీ లేదా డేటాసెంటర్ కనెక్షన్ ద్వారా అప్‌లోడ్ చేయాలంటే, సైన్-ఇన్‌తో ఆమోదం పొందిన ముందస్తు తనిఖీ లేదా స్థిరపడిన ఖాతా అవసరం. Tor ద్వారా అయితే ధృవీకరించబడిన మినహాయింపు అవసరం.

## గోప్యత

- **నిర్వాహకుడు** దుర్వినియోగాన్ని గుర్తించడానికి ముడి IP చిరునామాలను మరియు ప్రచురణల కంటెంట్‌ను నిల్వ చేస్తాడు, వర్గీకరణ కోసం IP చిరునామాలను మూడవ పక్ష ప్రదాతకు పంపుతాడు (డిఫాల్ట్‌గా proxycheck.io).
- **కమ్యూనిటీలకు** దేశ కోడ్, IP రిస్క్, కనెక్షన్ రకం అంచనా మరియు ఉత్తీర్ణత లేదా వైఫల్య ఫలితం మాత్రమే అందుతాయి. వాటికి ముడి IP గానీ సైన్-ఇన్ ఖాతా గానీ ఎప్పుడూ అందవు.
- **సైన్-ఇన్‌లు** ఎలాంటి ప్రొఫైల్ డేటాను అడగవు. సేవకు Google, Apple లేదా Telegram నుండి ఒక ఖాతా ID మాత్రమే అందుతుంది, పేరు, ఇమెయిల్ లేదా ఫోటో ఎప్పుడూ అందవు. సేవ ఆ IDని పోస్ట్‌తో పాటు, స్వయంచాలక తొలగింపు లేకుండా ఉంచుకుంటుంది, తద్వారా నిషేధం ఆ ఖాతాకు కూడా వర్తిస్తుంది.
- **VPN వాడే రచయితలు** సైన్ ఇన్ చేసినప్పుడు తమ నిజమైన IP చిరునామాను దాచి ఉంచుకుంటారు: సేవకు VPN చిరునామా మాత్రమే కనిపిస్తుంది.

## రేట్ పరిమితులు

స్కోర్ ఇవ్వడానికి ముందే, పోస్ట్‌లు, ప్రత్యుత్తరాలు మరియు ఓట్ల కోసం తమ గంటవారీ లేదా రోజువారీ కోటాను మించిన రచయితలను సేవ తిరస్కరిస్తుంది. ఖాతా వయస్సు మరియు మంచి ప్రతిష్ఠతో కోటాలు పెరుగుతాయి, నిషేధాలు లేదా తొలగింపుల తర్వాత తగ్గుతాయి.

## API

`spamblocker.bitsocial.net/api/v1` కు సాపేక్షంగా ప్రధాన రూట్‌లు:

| రూట్                     | కాలర్                     | ఉద్దేశ్యం                                        |
| ------------------------ | ------------------------- | ------------------------------------------------ |
| `POST /evaluate`         | ఛాలెంజ్ iframe, కమ్యూనిటీ | ప్రచురణకు స్కోర్ ఇచ్చి దాని సెషన్‌ను సృష్టించడం  |
| `POST /challenge/verify` | కమ్యూనిటీ                 | సెషన్ ఫలితాన్ని మరియు IP సమాచారాన్ని చదవడం       |
| `POST /precheck`         | ముందస్తు తనిఖీ iframe     | అప్‌లోడ్‌కు ముందు డ్రాఫ్ట్‌కు స్కోర్ ఇవ్వడం      |
