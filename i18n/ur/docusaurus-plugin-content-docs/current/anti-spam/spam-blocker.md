# Spam Blocker

Spam Blocker کسی کمیونٹی کے قبول کرنے سے پہلے پوسٹس، جوابات اور ووٹوں کو سپیم کے رسک کے لحاظ سے اسکور دیتا ہے۔ کمیونٹی چیلنج پیکیج انسٹال کرتی ہے، جو ہر اشاعت کو ایک Spam Blocker سروس کو بھیجتا ہے۔ Bitsocial ایسی ایک سروس `spamblocker.bitsocial.net` پر چلاتا ہے۔

- **`@bitsocial/spam-blocker-challenge`** وہ اوپن سورس چیلنج پیکیج ہے جسے کمیونٹیز انسٹال کرتی ہیں۔ اس کا انضمامی معاہدہ، مشترکہ اسکیمے اور API عوامی ہیں۔
- **میزبانی شدہ سروس** اشاعتوں کو اسکور دیتی ہے اور CAPTCHA اور سائن اِن کے صفحات فراہم کرتی ہے۔ اس کے تفصیلی اوزان اور اندازے نجی ہیں، جیسا کہ [ماخذ پالیسی](https://github.com/bitsocialnet/spam-blocker/blob/master/docs/architecture/hosted-service-source-policy.md) میں وضاحت کی گئی ہے۔

**ماخذ کوڈ:** [github.com/bitsocialnet/spam-blocker](https://github.com/bitsocialnet/spam-blocker)

## اشاعت کی جانچ کیسے ہوتی ہے

1. کمیونٹی کا چیلنج دستخط شدہ اشاعت سروس کو بھیجتا ہے، جو 0 اور 1 کے درمیان ایک رسک اسکور واپس کرتی ہے۔
2. اگر اسکور کمیونٹی کی خودکار قبولیت کی حد سے کم ہو تو اشاعت منظور ہو جاتی ہے۔ اگر یہ خودکار مسترد کی حد کے برابر یا اس سے زیادہ ہو تو اشاعت ناکام ہو جاتی ہے اور مصنف کو وجہ دکھائی جاتی ہے۔
3. ان دونوں کے درمیان، اگر مصنف کا پچھلے 30 دنوں کا سائن اِن کافی ہو تو اسی کو دوبارہ استعمال کیا جاتا ہے۔ ورنہ مصنف کو تصدیق کا صفحہ ملتا ہے: اگر صرف CAPTCHA سے کام چل سکتا ہو تو CAPTCHA، ورنہ سائن اِن۔
4. پھر کمیونٹی سروس سے نتیجے کی تصدیق کرتی ہے اور ملک، IP رسک اور کنکشن کی قسم کے لیے اپنے قواعد لاگو کرتی ہے۔

منسلک فائل اپ لوڈ کرنے سے پہلے کلائنٹ یہی جانچ پیشگی جانچ کے طور پر چلا سکتا ہے، تاکہ جن مصنفین کو مسترد ہونا ہو وہ کبھی اپ لوڈ ہی نہ کریں۔

| مواد اور لنکس    | متن اور لنکس کا تجزیہ، بشمول دہرایا گیا مواد۔                                                                                                    |

| IP انٹیلیجنس     | کنکشن کی قسم (Tor، VPN، پراکسی، ڈیٹا سینٹر) اور IP رسک۔ خام IP پتے کبھی کمیونٹیز کے ساتھ شیئر نہیں کیے جاتے۔                                     |
| جڑے ہوئے اکاؤنٹس | ایک ہی نیٹ ورک سے پوسٹ کرنے والے بہت سے اکاؤنٹس رسک کو بتدریج بڑھاتے ہیں۔                                                                        |
| سماجی تصدیق      | مصنف کے اکاؤنٹ پر پہلے کیے گئے سائن اِن رسک کم کرتے ہیں۔                                                                                         |

## تصدیق

ہر مکمل کیا گیا مرحلہ رسک اسکور کو ایک ضارب سے ضرب دیتا ہے، اور جب نتیجہ 0.4 سے کم ہو تو اشاعت منظور ہو جاتی ہے۔

| مرحلہ                                      | ضارب       |
| ------------------------------------------ | ---------- |
| CAPTCHA (Cloudflare Turnstile)             | × 0.7      |
| Google، Apple یا Telegram کے ساتھ سائن اِن | × 0.6      |
| دوسرے، مختلف فراہم کنندہ کے ساتھ سائن اِن  | مزید × 0.5 |

اگر CAPTCHA کافی نہ ہو تو اس کے بعد سائن اِن آتا ہے۔ اگر سائن اِن کافی نہ ہو تو اس کے بعد CAPTCHA آتا ہے، بشرطیکہ اس سے جانچ مکمل ہو جائے، ورنہ کسی دوسرے فراہم کنندہ کے ساتھ سائن اِن۔

### یاد رکھے گئے سائن اِن

سروس وہ اکاؤنٹ یاد رکھتی ہے جس سے مصنف نے آخری بار سائن اِن کیا تھا۔ بعد کی کوئی پوسٹ جسے تصدیق درکار ہو، اسی اکاؤنٹ کو دوبارہ استعمال کرتی ہے، گویا مصنف نے پھر سے سائن اِن کیا ہو، جب تک مصنف کم از کم ہر 30 دن میں ایک بار اس کے ساتھ پوسٹ کرتا رہے۔ جب یہ کافی ہو تو پوسٹ CAPTCHA کے بغیر منظور ہو جاتی ہے۔ کمیونٹی میں اس اکاؤنٹ سے منسلک پابندی اس سہولت کو ختم کر دیتی ہے، اور سروس سے اس کے فراہم کنندہ کو ہٹانا بھی۔

## کنکشن پالیسیاں

کمیونٹیز Tor، VPN (بشمول iCloud Private Relay)، پراکسی اور ڈیٹا سینٹر کنکشنز سے آنے والی اشاعتوں کو محدود کر سکتی ہیں۔ میزبانی شدہ سروس پر:

- **VPN، پراکسی اور ڈیٹا سینٹر کنکشنز** سائن اِن کے بعد پوسٹ کر سکتے ہیں۔ صفحہ وضاحت کرتا ہے کہ سائن اِن کیوں ضروری ہے اور VPN بند کر کے اس کے بغیر کیسے پوسٹ کیا جا سکتا ہے۔ اس کے بعد کمیونٹی میں لگنے والی پابندی سائن اِن کے لیے استعمال کیے گئے اکاؤنٹ پر بھی لاگو ہوتی ہے۔
- **مستحکم اکاؤنٹس**، جنہوں نے غیر محدود کنکشنز سے 3 الگ الگ دنوں میں جانچ پاس کی ہو، مستثنیٰ ہیں۔
- **Tor** محدود ہی رہتا ہے، سوائے ان مصنفین کے جنہیں کمیونٹی کی ترتیب دی ہوئی استثنا حاصل ہو: ماڈریٹر کا کردار، کمیونٹی کی وائٹ لسٹ، یا تصدیق شدہ `.bso` نام۔

Forge Images پر اپ لوڈ کی جانے والی منسلک فائلیں بھی انہی قواعد کی پابند ہیں۔ VPN، پراکسی یا ڈیٹا سینٹر کنکشن کے ذریعے اپ لوڈ کے لیے ایسی پیشگی جانچ درکار ہے جو سائن اِن کے ساتھ پاس ہوئی ہو، یا ایک مستحکم اکاؤنٹ۔ Tor کے ذریعے اس کے لیے تصدیق شدہ استثنا درکار ہے۔

## پرائیویسی

- **آپریٹر** غلط استعمال کا پتہ لگانے کے لیے خام IP پتے اور اشاعتوں کا مواد محفوظ کرتا ہے، اور درجہ بندی کے لیے IP پتے کسی بیرونی فراہم کنندہ کو بھیجتا ہے (بطورِ طے شدہ proxycheck.io)۔
- **کمیونٹیز** کو صرف ملک کا کوڈ، IP رسک، کنکشن کی قسم کا اندازہ اور پاس یا فیل کا نتیجہ ملتا ہے۔ انہیں خام IP یا سائن اِن والا اکاؤنٹ کبھی نہیں ملتا۔
- **سائن اِن** کوئی پروفائل ڈیٹا نہیں مانگتے۔ سروس کو Google، Apple یا Telegram سے صرف اکاؤنٹ ID ملتی ہے، کبھی نام، ای میل یا تصویر نہیں۔ سروس یہ ID پوسٹ کے ساتھ رکھتی ہے، خودکار حذف کے بغیر، تاکہ پابندی اکاؤنٹ پر بھی لاگو ہو۔
- **VPN استعمال کرنے والے مصنفین** سائن اِن کرتے وقت اپنا اصل IP پتہ پوشیدہ رکھتے ہیں: سروس کو صرف VPN کا پتہ نظر آتا ہے۔

## شرح کی حد بندی

اسکور دینے سے پہلے، سروس ان مصنفین کو مسترد کر دیتی ہے جو پوسٹس، جوابات اور ووٹوں کے لیے اپنے فی گھنٹہ یا روزانہ کوٹے سے تجاوز کریں۔ کوٹے اکاؤنٹ کی عمر اور اچھی ساکھ کے ساتھ بڑھتے ہیں، اور پابندیوں یا ہٹائے جانے کے بعد کم ہو جاتے ہیں۔

## API

`spamblocker.bitsocial.net/api/v1` کی نسبت سے اہم روٹس:

| روٹ                      | کال کرنے والا         | مقصد                                         |
| ------------------------ | --------------------- | -------------------------------------------- |
| `POST /evaluate`         | چیلنج iframe، کمیونٹی | اشاعت کو اسکور دینا اور اس کا سیشن بنانا     |
| `POST /challenge/verify` | کمیونٹی               | سیشن کا نتیجہ اور IP انٹیلیجنس پڑھنا         |
| `POST /precheck`         | پیشگی جانچ iframe     | اپ لوڈ سے پہلے مسودے کو اسکور دینا           |
| `GET /iframe/:sessionId` | مصنف کا براؤزر        | تصدیق کا صفحہ                                |
| `POST /upload/authorize` | مصنف کا کلائنٹ        | Forge Images کے لیے منسلک فائل کی اجازت دینا |

درخواست پر دستخط اور جواب کے اسکیموں سمیت مکمل معاہدہ [spam-blocker README](https://github.com/bitsocialnet/spam-blocker#api-contract) میں موجود ہے۔
